# Редактируемые юридические страницы

## Что сделано

- В Payload добавлен раздел «Юридические страницы» с вкладками для `privacy.html` и `consent.html`.
- Заголовки и содержимое редактируются штатным визуальным редактором: поддерживаются заголовки, списки, ссылки и форматирование.
- Текущие тексты обеих страниц перенесены в CMS; повторный запуск сидера не перезаписывает редакторские изменения.
- Страницы получают опубликованный HTML из публичного API, сохраняя статическое содержимое как резервное.

## Изменённые файлы и службы

- `cms/src/globals/LegalPages.ts` и `cms/src/payload.config.ts`.
- `cms/src/migrations/20260816_090740_legal_pages.ts`, JSON-снимок и индекс миграций.
- `cms/src/scripts/seed-legal-pages.ts`, `cms/package.json`, `cms/src/payload-types.ts`.
- `js/legal-content.js`, `cms/public/landing/js/legal-content.js` и подключения в четырёх HTML-копиях.
- `cms/README.md`.
- Локальная SQLite-база и работающий Next.js/Payload на порту 3000.

## Проверки

- `npx tsc --noEmit` — успешно.
- `npm run lint` — 0 ошибок, 13 предупреждений в миграциях и существовавших шаблонных файлах.
- Миграция применена; API возвращает 20 149 символов HTML политики и 6 039 символов HTML согласия.
- `/admin/globals/legal-pages`, `privacy.html` и `consent.html` отвечают HTTP 200.
- Повторный `npm run seed:legal-pages` подтвердил отсутствие перезаписи данных.
- Impeccable detector — замечаний нет; `git diff --check` — успешно.

## Решения

- Использован штатный Lexical и вычисляемые HTML-поля Payload без новых зависимостей.
- Статический текст остаётся fallback при недоступном API.

## Остаток

- Вручную проверить сохранение тестовой правки после входа в админку.
- После изменения кода требуется семантическое обновление Graphify; внешние LLM и платные API не подключались.

## Риски

- Полный браузерный автотест не запускался: Playwright Chromium отсутствует локально.
- Юридические тексты требуют проверки специалистом перед публикацией.

## Откат

- Остановить сервер, выполнить down для миграции либо восстановить `cms/cms.db.backup-20260816-legal-pages`, затем вернуть перечисленные файлы из Git.
