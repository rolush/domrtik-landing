# Крупные миниатюры изображений в админке

## Что сделано

Выбранные медиафайлы во всех upload-полях CMS показываются карточкой с миниатюрой 112×112 px, именем файла, размером, разрешением и форматом. На узком экране миниатюра уменьшается до 80×80 px. Изображение вписывается целиком, поэтому портретные сертификаты не обрезаются.

## Изменённые файлы и службы

- `cms/src/app/(payload)/custom.scss`
- Локальный Next/Payload dev-сервер подхватил стили автоматически.

## Проверки

- `npm run lint` — ошибок нет, остались 9 прежних предупреждений.
- Impeccable detector — замечаний нет.
- Скомпилированный CSS локальной админки содержит новые правила карточки и миниатюры.

## Решения

Использована штатная карточка Payload: она уже содержит характеристики файла. Изменён только общий стиль, поэтому решение охватывает категории, товары, фон, постеры, карту и сертификаты без дублирования компонентов.

## Остаток

Нет.

## Риски

Увеличенные карточки занимают больше высоты в длинных массивах; на мобильном размер уменьшен.

## Откат

Удалить блок `.upload-field-card.upload-field-card--size-medium` и связанный media query из `cms/src/app/(payload)/custom.scss`.
